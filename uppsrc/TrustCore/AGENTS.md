# AGENTS - TrustCore

**Scope**: Applies to `uppsrc/TrustCore`.

## Purpose
Trust network modeling, PageRank/TrustRank reputation flows, and AppleSeed trust metrics:
- `TrustCore.h`: Main header and types.
- `Net.{h,cpp}`: Directed trust networks, node reputation scoring, damping, and iteration.
- `Graph.{h,cpp}`: Trust adjacency representations.
- `AppleSeed.cpp`: Trust propagation and seed-based trust scoring.
